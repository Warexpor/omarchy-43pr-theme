# Third-party plugins

## vm.steam-progress

Not vendored here (clone on restore):

```bash
omarchy plugin clone https://github.com/jhonoryza/omarchy-steam-progress.git
# or:
# git clone https://github.com/jhonoryza/omarchy-steam-progress.git ~/.config/omarchy/plugins/vm.steam-progress
```

Then ensure `shell.json` lists `vm.steam-progress` (already in `system/config/omarchy/shell.json`).
